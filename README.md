# The One

Free polyphonic synth plug-in by Dani Koenig, inspired by the Moog One. VST3, Audio Unit and CLAP for macOS (Apple Silicon).

- 16 voices, 3 oscillators, ring mod, noise, SVF + Ladder filter, 3 envelopes, 4 LFOs
- Chord Memory (learn a chord, every key plays it transposed)
- 3 effect slots (delay, chorus, flanger, phaser, bit crusher, resonator)
- No presets, programmed from scratch

Installation: see [INSTALL.txt](INSTALL.txt). Builds run on GitHub Actions (see `.github/workflows/build.yml`).
